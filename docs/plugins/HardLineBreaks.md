该插件会自动将 Markdown 文本中的单行换行符转换为 HTML 输出中的硬换行。此插件默认未启用，因为这不符合标准 Markdown 的语义，但如果你希望与 [[Obsidian 兼容性|Obsidian]] 保持一致，可以启用它。

> [!note]
> 有关如何添加、移除或配置插件的信息，请参见 [[configuration#Plugins|配置]] 页面。

此插件没有配置选项。

## API

- 分类：转换器
- 函数名：`Plugin.HardLineBreaks()`
- 源码：[quartz/plugins/transformers/linebreaks.ts](https://github.com/jackyzha0/quartz/blob/v4/quartz/plugins/transformers/linebreaks.ts)
